# Contributing to MediGen AI Pro

MediGen AI Pro is **proprietary software** (see [LICENSE](LICENSE)).
The code is public for demonstration and portfolio purposes, so external
code contributions are **not accepted** at this time.

You are welcome to:

- **Report a bug** — open an issue using the Bug Report template.
- **Suggest a feature** — open an issue using the Feature Request template.
- **Report a security issue** — please do **not** open a public issue;
  follow [SECURITY.md](SECURITY.md) instead.

## Reporting bugs well

A useful bug report includes:

1. The version (shown in the app footer / Settings).
2. What you did, step by step.
3. What you expected, and what actually happened.
4. A screenshot, if the problem is visual.

Thank you for helping improve MediGen AI Pro.

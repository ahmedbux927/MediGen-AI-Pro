# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 101.03 (current) | ✅ |
| Older versions | ❌ |

## Reporting a vulnerability

If you find a security issue in MediGen AI Pro, please report it privately
before disclosing it publicly:

- **LinkedIn:** https://www.linkedin.com/in/ahmed-bux-5a096a310
- **GitHub:** open a private security advisory on this repository
  (Security → Advisories → Report a vulnerability)

Please include what you found, how to reproduce it, and the version you
tested. You can expect an acknowledgement within a few days.

## Scope notes

- MediGen AI Pro is designed to run on a trusted local network (LAN).
  Exposing it directly to the internet is outside its intended deployment
  model.
- Real shop credentials, API keys and data are never part of this
  repository; test fixtures use dummy values only.
